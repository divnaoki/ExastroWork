# 自動代入値設定（代入値自動登録設定）

Exastro ITA v2.x「代入値自動登録設定」メニューの手動登録ガイド。本アプリは登録を行わない（設計のみ）。

## 複数具体値変数の構成
- 変数: **`VAR_vm`**（複数具体値変数 / メンバー変数つき）。
- バンドルONのパラメータシート「VM構築パラメータ」の各行（=1VM）が `VAR_vm` の1要素になる。
- **代入順序**が配列要素の順番（index）＝ Playbookの `loop: "{{ VAR_vm }}"` 展開順。
- Playbook側参照: `item.<メンバー>`（例 `item.name` / `item.cpu_count` / `item.guest_ip_address`）。

## 代入順序の設計
- 同一Hyper-Vホスト内のVMを、登録したい `loop` 順で **代入順序 1,2,3…** と振る。
- 全メンバー変数で**同一の代入順序**を揃えること（順序がズレると別VMの値が混在する）。
- 例: hv01 → 代入順序1=rhel01 / 2=win01 / 3=win02。

## 注意
- バンドル/代入順序のExastro UI上の正確な名称・登録用Excelの列見出しは実メニューに依存（手動登録時に確認）。
- `VAR_vm.guest_admin_password` は機密。Playbookの該当タスクは `no_log: true` 済み。
